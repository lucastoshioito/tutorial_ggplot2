# Graphics with ggplot2

A practical ggplot2 tutorial and a home for reusable figures. The main tutorial covers common chart types, and individual plot pages can be added whenever they are useful.

The website is built with [Quarto](https://quarto.org/) and will be published at [lucastoshioito.github.io/tutorial_ggplot2](https://lucastoshioito.github.io/tutorial_ggplot2/).

## Adding a plot note

1. Copy `plots/_template.qmd` to a short descriptive filename inside `plots/`.
2. Replace the example content with the plot, explanation, and any useful links.
3. Add the new page to the website navigation in `_quarto.yml`.
4. Preview the website with `quarto preview`.
